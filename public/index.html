آماده شنیدن (fa-IR)
مرورگر شما از Web Speech API پشتیبانی نمی‌کند. برای استفاده از میکروفون فارسی، صفحه را در مرورگر Google Chrome یا Edge (روی HTTPS یا localhost) باز کنید. با این حال، همچنان می‌توانید تمام فرمان‌ها را در کادر متنی پایین تایپ یا روی مثال‌ها کلیک کنید.
برای صحبت کلیک کن
فارسی (fa-IR) هم امتیاز بازی و هم محاسبه ریاضی را می‌فهمد

مثلاً بگو: «۱۰ رو منهای ۳ کن» یا «۲۰ امتیاز به سارا اضافه کن»
